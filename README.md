# HeartGuard: Heart Disease Prediction Using Machine Learning

HeartGuard is a full-stack heart disease risk prediction system. It uses a trained machine-learning model to estimate whether a patient has a lower or higher likelihood of heart disease based on selected clinical indicators.

## Project Purpose

This project is developed as a complete software engineering system, not only a machine-learning notebook. It includes a frontend interface, backend prediction API, Firebase integration, machine-learning pipeline, testing, Git/GitHub workflow, and documentation.

## Important Disclaimer

HeartGuard is an educational clinical decision-support prototype. It does not provide a medical diagnosis. Predictions must be interpreted by qualified healthcare professionals.
