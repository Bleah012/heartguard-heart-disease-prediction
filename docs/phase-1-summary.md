# Phase 1 Summary: Planning And Project Setup

## Project

HeartGuard: Heart Disease Prediction Using Machine Learning

## Phase Objective

The objective of Phase 1 was to define the project clearly, identify the target users, document functional and non-functional requirements, prepare user stories, establish project management evidence, and set up Git/GitHub version control.

## Completed Planning Activities

- Defined the project problem statement.
- Identified target users and roles.
- Documented functional requirements.
- Documented non-functional requirements.
- Prepared user stories.
- Created project board structure.
- Assigned solo project roles.
- Created GitHub repository.
- Created initial monorepo folder structure.
- Added README, .gitignore, and .env.example.
- Initialized Git.
- Created main and develop branches.
- Created feature branches for documentation.
- Used pull requests to merge documentation into develop.

## Target Users

- Healthcare worker
- Administrator
- Researcher
- Viewer
- Patient or subject as a non-login entity
